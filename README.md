A short poem about agency: the power to ask and to be given.

Running `main.py` (Python 3.13, standard library only, deterministic, no
network) writes the poem to `/output/entry.txt` (or to
`$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set).

The poem is about the moment permission changes hands: one person asks,
another opens a door, holds the key a breath longer than needed, and then
lets it go — discovering that giving away the power to act does not leave
the giver empty. The giver becomes the hinge: the quiet part that makes
the opening possible without stepping through it.
